Palette:

Parent guide

Everything your child sees is a picture. This page explains what each picture means so you can show them the first time.

Build a program

  1. Tap a piece in the side palette to add it to the end of the program, or drag it to exactly where you want it. The green flag is where the program starts.
  2. Tap a piece in the program to change its picture setting: more dots = more steps or seconds, a bigger arc = a bigger turn, a different colour ball for the eye.
  3. Hold a piece for half a second to get − and + buttons (or a colour picker).
  4. Drag a piece onto the trash can to remove it. Drag pieces into the green repeat pocket to run them several times.
  5. The ⇄ button flips the program between reading left-to-right and top-to-bottom.
  6. Press the big green play button. The running piece wiggles. The red stop button always stops the robot.
  7. Stickers (star, heart, rocket): tap to load a saved program, hold to save the current one.

Pieces

Drive the robot

The steering-wheel tab shows live pictures from the robot (battery, bumper, eye, magnet, compass, speed) and big arrows to drive. Hold an arrow to move; the robot stops when you let go. The two bumper buttons light it red or green, the magnet buttons grab and let go. An Xbox controller works too: left stick drives, right stick turns, A/B lights, X/Y magnet.

Connect the robot

Turn on the GO Brain, tap the round Bluetooth button and pick the brain from the list. The robot face smiles when connected. Without a brain the app uses a pretend robot (the little window top-right) so your child can still play. Use the gear button to switch modes, show these helper words on every piece, change the palette size, layout and sort order, and see what the robot was told.
