# 14 — VEX GO glossary

Terms as VEX uses them, in one alphabetical list, with a pointer to the document that goes deeper. Words that are *this project's* vocabulary (pieces, strip, pretend robot, challenge board, sticker slot) are in [07](07-kid-gui-design.md) and [10](10-challenge-mode.md), not here. Terms that sound official but are **not** VEX vocabulary are listed at the end so nobody writes them into the UI or docs by mistake.

Research date: 2026-11-03. Sources are the VEX Library (kb.vex.com), api.vex.com and education.vex.com; see [11](11-vex-go-electronics.md)–[13](13-vex-go-kits-and-builds.md) and [15](15-vex-go-ecosystem.md) for the URLs behind each entry.

## A–Z

**Acts & Asks** — the teacher-script format inside a STEM Lab's Engage section: Instruct, Model, Facilitate, Remind, Ask. [15](15-vex-go-ecosystem.md)

**Activity / Activity Series** — short stand-alone classroom activities on education.vex.com, grouped by theme, separate from Units. [15](15-vex-go-ecosystem.md)

**Adaptation Claw** — a build and STEM Lab unit (Helping Hand) where students adapt a claw to pick up objects. Not a kit.

**Angle Beam** — a bent one-wide beam: Yellow 45°, Red 60°, Green small 90°, Orange larger 90°. [12](12-vex-go-structural-parts.md)

**Beam** — a one-hole-wide plastic bar; ten lengths, one colour each. See also Large Beam, Plate. [12](12-vex-go-structural-parts.md)

**Blocks** — the drag-and-drop coding mode of VEXcode GO (hat, stack, boolean, reporter and C-shaped blocks). [15](15-vex-go-ecosystem.md), [03](03-block-reference.md)

**Blue Wheel** — the smooth, round-hub, free-rolling wheel used as the Code Base idler. [12](12-vex-go-structural-parts.md)

**Boost / Drop** — the two states of the Electromagnet: a one-second pulse that strengthens the field to grab a disk, or reverses it to release. [11](11-vex-go-electronics.md)

**Brain (GO Brain)** — the controller: 4 Smart Ports, an Eye Sensor port, a Battery port, a power button, Bluetooth Low Energy, a built-in inertial sensor. [11](11-vex-go-electronics.md)

**Brake / Coast / Hold** — the three stopping modes for motors and the drivetrain. Brake resists motion, coast lets it roll, hold actively returns to position. Default: brake. [03](03-block-reference.md)

**Bumper** — in GO, always the LED Bumper. There is no separate bumper switch. [11](11-vex-go-electronics.md)

**builds.vex.com** — the shortcut to the GO build instructions page. [13](13-vex-go-kits-and-builds.md)

**Calibrate** — the 2-second still period in which the Brain's gyro zeroes itself at the start of a project. [11](11-vex-go-electronics.md)

**Capped Pin / Capped Shaft** — a pin or shaft with a cap on one end so it cannot pass through; used in tight gear stacks. The Pink Pin is the capped pin. [12](12-vex-go-structural-parts.md)

**Choice Board** — a grid of nine independent student activities at the end of a STEM Lab unit, for early finishers or assessment. [15](15-vex-go-ecosystem.md)

**Classroom app (VEX Classroom)** — the fleet-management app: update firmware, rename brains, locate a brain, read battery and sensor data. [11](11-vex-go-electronics.md)

**Classroom Bundle** — 5, 10 or 15 Kits with Storage plus field walls, spare parts, charging hubs and bags. [13](13-vex-go-kits-and-builds.md)

**Code Base / Code Base 2.0** — the standard two-motor coding robot. The original has four wheels; 2.0 (Nov 2024) has two powered wheels and a caster and is the recommended build. [13](13-vex-go-kits-and-builds.md)

**codego.vex.com** — the web version of VEXcode GO (Chrome or Edge). [15](15-vex-go-ecosystem.md)

**Competition (VEX GO Competition, VGOC)** — the classroom-scale competition with four fixed Missions, each in four Stages. [15](15-vex-go-ecosystem.md)

**Competition Base / Base + Claw / Advanced** — the three "Hero Robot" builds for the competition. [13](13-vex-go-kits-and-builds.md)

**Connector** — a plastic corner (Red, Yellow, Blue, 90°) or parallel (Green, Orange) joining piece with round pegs and holes. [12](12-vex-go-structural-parts.md)

**Console (Print Console / Monitor Console)** — the VEXcode GO panel that shows `print` output and live sensor or variable values. [15](15-vex-go-ecosystem.md)

**Continuum (VEX Continuum)** — VEX's K–12 progression: 123 → GO → AIM → IQ → EXP → V5 → CTE, plus AIR. [15](15-vex-go-ecosystem.md)

**Crash** — the drivetrain's "detected crash" flag, set by the Brain's accelerometer on a sudden stop. [05](05-drive-tab-and-sensors.md)

**Devices (window)** — the VEXcode GO panel where you add the Code Base, Robot Arm, or individual Motor, LED Bumper, Electromagnet and Eye Sensor devices and assign ports. [15](15-vex-go-ecosystem.md)

**Disk (GO Disk)** — the red, green and blue metal-cored disks the Electromagnet lifts. Called pucks in this app. [12](12-vex-go-structural-parts.md)

**Drive for / Turn for** — the drivetrain blocks that move a set distance (mm or inches) or angle (degrees) and wait until done. [03](03-block-reference.md)

**Drive tab** — the VEXcode GO tab that turns the tablet into a remote control with on-screen joysticks and sensor readouts. [05](05-drive-tab-and-sensors.md)

**Drive modes** — the four joystick layouts in the Drive tab: Tank, Left Arcade, Right Arcade, Split Arcade. [05](05-drive-tab-and-sensors.md)

**Drivetrain** — the virtual device made of the left and right motors plus the Brain's inertial sensor; the target of the Drive for, Turn for and heading blocks. [11](11-vex-go-electronics.md)

**Electromagnet** — the Smart Port device that grabs and releases disks. [11](11-vex-go-electronics.md)

**Engage / Play / Share** — the three sections of every STEM Lab. [15](15-vex-go-ecosystem.md)

**Example Projects** — the sample programs under File → Open Examples in VEXcode GO. [15](15-vex-go-ecosystem.md)

**Eye Sensor (GO Eye Sensor, "GO Optical Sensor")** — the colour, hue, brightness and object sensor on its own blue-green port. [11](11-vex-go-electronics.md)

**Field Tile / Field Wall** — the 12-inch snap-together floor squares and walls that make a practice area or the competition field. [12](12-vex-go-structural-parts.md)

**Firmware** — the software on the Brain, updated over Bluetooth from the Classroom app or VEXcode GO. VEX does not call it VEXos for GO. [11](11-vex-go-electronics.md)

**Gear (Red 8T, Green 16T, Blue 24T, Pink 24T idler)** — the four gears; only Pink has a round hub. [12](12-vex-go-structural-parts.md)

**Gear ratio** — the one drivetrain parameter VEXcode GO lets you set (default 1, as the Code Base drives wheels directly). [13](13-vex-go-kits-and-builds.md)

**Gray Pin** — the square-pegged pin that transfers motor rotation through a beam. [12](12-vex-go-structural-parts.md)

**Gray Wheel** — the treaded square-hub drive wheel: about 51 mm diameter, 160 mm per revolution. [12](12-vex-go-structural-parts.md)

**Gyro / Inertial Sensor** — the gyro and accelerometer inside the Brain; gives heading, rotation, pitch/roll/yaw, crash and acceleration. There is no separate gyro part. [11](11-vex-go-electronics.md)

**Heading** — the direction the Brain faces, 0–359.99°, clockwise positive, 0 at project start. **Rotation** is the same angle without wrapping. [03](03-block-reference.md)

**Help** — the VEXcode GO panel that explains the selected block. [15](15-vex-go-ecosystem.md)

**Hero Robot** — VEX's name for a published competition build. [13](13-vex-go-kits-and-builds.md)

**Hue** — the Eye Sensor's colour angle, 0–359°; red 340–20, green 75–154, blue 160–254. [11](11-vex-go-electronics.md)

**Kit (GO Kit / Kit with Storage)** — one robot's worth of parts; "with Storage" adds sorted bins. [13](13-vex-go-kits-and-builds.md)

**Knob (Hand Knob)** — the orange square-hub crank. [12](12-vex-go-structural-parts.md)

**Lab / Unit** — a STEM Lab unit is a sequence of Labs (lessons) on one theme. [15](15-vex-go-ecosystem.md)

**Large Beam** — a two-hole-wide beam with a half-offset centre row; nine lengths. [12](12-vex-go-structural-parts.md)

**Leaderboard (VEX GO Leaderboard)** — the free web scoreboard and timer for classroom competitions. [15](15-vex-go-ecosystem.md)

**LED Bumper** — the combined bumper switch and red/green light. [11](11-vex-go-electronics.md)

**Library (VEX Library)** — VEX's knowledge base at kb.vex.com (shortcut library.vex.com). [15](15-vex-go-ecosystem.md)

**Locate** — the Classroom app command that makes a brain's LED turn yellow so you can find it. [11](11-vex-go-electronics.md)

**Magnet (North / South)** — the two permanent magnets moulded onto short beams; different from the Electromagnet. [12](12-vex-go-structural-parts.md)

**Mission** — one of the four VEX GO Competition games: Mars Math Expedition, Ocean Science Exploration, Village Engineering Construction, City Technology Rebuild. [15](15-vex-go-ecosystem.md)

**Monitor** — the toolbar icon that opens the Print Console and Monitor Console. [15](15-vex-go-ecosystem.md)

**My Blocks** — user-defined blocks in VEXcode GO. [03](03-block-reference.md)

**Name Plate** — the writable white plate used as a competition licence plate. [12](12-vex-go-structural-parts.md)

**Near / Far** — the Eye Sensor's two range settings (18 mm / 40 mm). [11](11-vex-go-electronics.md)

**One Stick Controller** — a single-joystick VEX controller that can pair to a GO Brain and drive a Code Base without code. [11](11-vex-go-electronics.md)

**Pacing Guide** — a STEM Lab unit's schedule document (cumulative and 1:1 variants). [15](15-vex-go-ecosystem.md)

**Parts Pack (A–D)** — the four replacement-parts packs. [12](12-vex-go-structural-parts.md)

**Parts Poster / Parts Ruler** — the categorised poster in every kit and the printable 1:1 ruler for identifying parts. [12](12-vex-go-structural-parts.md)

**PD+ (VEX PD+)** — VEX's professional-development site with the GO Educator Certification course and the professional learning community. [15](15-vex-go-ecosystem.md)

**Pin (Red 1x1, Green 1x2, Pink capped, Gray square)** — the four connector pins. [12](12-vex-go-structural-parts.md)

**Pin Tool** — the pin puller/pusher/lever tool shared with VEX IQ. [12](12-vex-go-structural-parts.md)

**Pitch** — the 12.7 mm hole spacing of the construction system; also used for one plastic thickness (6.35 mm) when naming pins. [12](12-vex-go-structural-parts.md)

**Plate** — a three- or four-hole-wide plastic sheet; five lengths. [12](12-vex-go-structural-parts.md)

**Pulley (Green, Orange)** — square-hub pulleys for ropes and rubber bands; the Green one also takes the Tire. [12](12-vex-go-structural-parts.md)

**Python** — the text coding mode added to VEXcode GO in version 4.60 (2025); runs in the browser, not on the brain. [04](04-python-api.md)

**Red Square Beam** — a 2x2 large beam with a square centre hole that turns with a shaft. [12](12-vex-go-structural-parts.md)

**Shaft (Red, Green, Plain, Capped)** — square metal axles. Red and Green have a flange; Plain and Capped do not. [12](12-vex-go-structural-parts.md)

**Shaft Collar** — the rubber ring that keeps a shaft or wheel from sliding. [12](12-vex-go-structural-parts.md)

**Slide Beam / Slide Block** — the linear-motion pair (the "sled") on the Robot Arm. [12](12-vex-go-structural-parts.md)

**Slotted Beam** — the pink beam with a slot that captures a rope or rubber band. [12](12-vex-go-structural-parts.md)

**Smart Motor (GO Smart Motor)** — the closed-loop motor with a square output socket. [11](11-vex-go-electronics.md)

**Smart Port** — one of the four numbered ports (1–4) on the Brain, 4P4C connector. The Eye port is not a Smart Port. [11](11-vex-go-electronics.md)

**Spin for / Spin to position** — the motor blocks for a relative or absolute move in degrees or turns. [03](03-block-reference.md)

**Standoff (Yellow, Blue, Orange)** — spacers with a peg at each end: 1, 2 or 4 thicknesses. [12](12-vex-go-structural-parts.md)

**Start / Stop** — the VEXcode GO toolbar buttons that run and halt a project. GO has no separate Download step. [01](01-how-vexcode-go-works.md)

**STEM Labs** — VEX's free online curriculum at education.vex.com/stemlabs/go. [15](15-vex-go-ecosystem.md)

**Step (Stepping)** — running a project one block at a time from the toolbar. [06](06-running-and-debugging.md)

**Switch (GO Switch)** — the three-position hand switch for running one motor or LED Bumper from the battery with no brain. [11](11-vex-go-electronics.md)

**Switch blocks** — a VEXcode GO feature that turns a block into an editable text box with the equivalent Python inside. [15](15-vex-go-ecosystem.md)

**Super Car** — the family of rubber-band, motorised and coded car builds. [13](13-vex-go-kits-and-builds.md)

**Thin Beam** — the thin blue beam with six round holes and one square end hole. [12](12-vex-go-structural-parts.md)

**Timeout** — how long a motor or drivetrain move may take before it gives up (default 5 s on the brain). [02](02-bluetooth-protocol.md)

**Toolbox** — the block palette in VEXcode GO, grouped by device since version 4.60. [15](15-vex-go-ecosystem.md)

**Torque (max torque)** — the motor current limit, set as a percentage; default 50 %. [11](11-vex-go-electronics.md)

**Tutorials** — the short embedded videos in VEXcode GO. [15](15-vex-go-ecosystem.md)

**Velocity** — speed as a percentage of maximum; default 50 % for drive, turn and motors. VEXcode scales it before sending. [04](04-python-api.md)

**VEXcode 5** — the next-generation web app at code.vex.com that will cover GO alongside the other platforms. [15](15-vex-go-ecosystem.md)

**VEXcode GO** — the official coding app (web, iPad, Android, Fire, Windows, Mac). [01](01-how-vexcode-go-works.md)

**VEXcode VR** — VEX's virtual-robot coding site; only one premium playground uses a GO robot (Mars Math Expedition). [15](15-vex-go-ecosystem.md)

**Wait / Wait until** — the control blocks that pause for a time or a condition. [03](03-block-reference.md)

**When started** — the hat block that begins a program; several may run at once. [03](03-block-reference.md)

## Terms that are not VEX vocabulary for GO

| Phrase | Why it is wrong | Say instead |
|---|---|---|
| Bumper Switch (as a GO part) | GO only has the LED Bumper | LED Bumper |
| Download / Run | GO never downloads a program to the brain | Start / Stop |
| Code mode / Controller mode | VEX says coding vs the Drive tab | Blocks, Python, Drive tab |
| VEXos (for GO) | VEX says "firmware" for GO | firmware |
| Gyro Sensor (as a part) | It is inside the Brain | Brain's inertial sensor |
| Kit Plus, Adaptation Kit, Field Kit | Not products | Kit, Adaptation Claw build, Competition Kit |
| Brain mount, battery cover | No such parts | pins directly to beams/plates |
| Season game (2024 game, 2025 game) | GO has fixed Missions, no yearly game | Mission |
| Ages 5+ | Official is Grades 3–5 / Ages 8+ | Ages 8+ |
| Fun Fact (as a lab section) | Not a STEM Lab section name | Background Information |
